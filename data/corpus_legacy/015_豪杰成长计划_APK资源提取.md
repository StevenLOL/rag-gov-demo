## 3. 技术栈分析

APK内 `lib/<abi>/libegret.so` 表明游戏基于 **Egret引擎**（白鹭科技的HTML5游戏引擎）。游戏主体是H5页面：
- 入口：`assets/game/index.html`
- 代码：`assets/game/js/`（20个JS文件，2.3MB，混淆后）
- 资源清单：`assets/game/resource/default.res.json`（Egret标准资源配置）
- 资源根目录：`assets/game/resource/`

Egret引擎的UI使用 **TexturePacker图集**（`.png` + `.json` 配对），JSON中记录每个切片在大图中的坐标、尺寸、偏移、旋转等信息。

## 7. UI图集与切片

![168套UI图集总览](images/haojie/sheets_overview.png)

### 7.1 Egret TexturePacker 图集格式

每套图集由两个文件组成：
- `<name>.png` — 合图大图
- `<name>.json` — 切图配置

JSON结构：
```json
{
  "frames": {
    "切片名": {
      "x": 4, "y": 4, "w": 500, "h": 30,
      "offX": 0, "offY": 0,
      "sourceW": 500, "sourceH": 30,
      "rotated": false, "trimmed": false
    }
  },
  "file": "achievement.png",
  "meta": {
    "app": "yeer", "version": "0.1.0",
    "image": "achievement.png",
    "format": "RGBA8888",
    "size": {"w": 508, "h": 246},
    "scale": 1
  }
}
```

### 7.2 切割算法

```python
for frame_name, frame in frames.items():
    x, y, w, h = frame['x'], frame['y'], frame['w'], frame['h']
    if frame.get('rotated'):
        crop = sheet.crop((x, y, x+h, y+w))  # 旋转存储时w/h互换
        crop = crop.rotate(90, expand=True)
    else:
        crop = sheet.crop((x, y, x+w, y+h))
    if frame.get('trimmed'):
        # 用透明填充还原原始尺寸
        full = Image.new('RGBA', (sourceW, sourceH), (0,0,0,0))
        full.paste(crop, (offX, offY))
        crop = full
    crop.save(f"{图集名}/{切片名}.png")
```
